# Baseline suppressions for packaging/lint/scan-build.sh.

# These are pre-existing clang static analyzer (scan-build) findings across
# all C packages (see the taskvine tech-debt audit's "static analysis"
# item). Captured by checker:file:line so that standing up scan-build in CI
# doesn't fail on day one over debt that predates it. A NEW finding at a
# different location is not covered by these entries and will fail the
# build.

# Confirmed real, but low-impact (left as-is, not fixed):
#   - taskvine/src/manager/vine_manager_get.c:68 -- reads an uninitialized
#     total_bytes before writing it in one call path, but the value is
#     discarded by the caller either way.
#   - makeflow/src/makeflow.c:2245 -- reachable only if rmsummary_create()'s
#     unchecked malloc() fails (OOM).
#   - dttools/src/bitmap.c:615 -- a truncated/malformed SGI RGB image file
#     can leave trailing scanline bytes uninitialized before they're OR'd
#     into pixel data; corrupts displayed pixels, not a crash or OOB access.
#   - resource_monitor/src/rmonitor_helper.c:307,350 -- the START() timing
#     macro reads msg.type before it's set; msg.type is unconditionally
#     overwritten shortly after in every actual call site, so this is inert.
#   - dttools/src/luapatt.c:48,57,65,72,147,265 -- the vendored Lua pattern
#     engine always passes an uninitialized MatchState.L to luaL_error();
#     reachable via a malformed pattern, but the local luaL_error() wrapper
#     ignores that argument and just aborts(). One-line fix available
#     (initialize ms.L in pattern_vmatch(), dttools/src/pattern.c) but not
#     applied yet -- low priority given six identical low-impact instances.

# Left unresolved -- needs deeper tracing than a source read could settle:
#   - dttools/src/bucketing_greedy.c:363 and
#     dttools/src/bucketing_det_greedy.c:373 -- couldn't fully rule out an
#     edge case (a top bucket range coming back "unbreakable" and being
#     omitted from the break-point list) without tracing the full
#     recursive splitting logic.

# re-running packaging/lint/scan-build.sh locally and diffing its output
# (via packaging/lint/scan-build-parse.py) against this file, rather than
# hand-editing entries.
